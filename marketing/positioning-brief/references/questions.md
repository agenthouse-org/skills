# Questions

Look in the sources first. Ask only what is still missing, most important first, and offer your reading so the user can confirm or correct it.

## Core

Ask these when the sources do not answer them. Most briefs need nothing else.

| Question | Look first in |
|---|---|
| Who is this for, and what makes them look for a solution now? | Website, sales material, CRM notes, call transcripts |
| What changes for them when it works? | Case studies, reviews, product pages |
| What do they use today instead? | Sales notes, lost-deal reasons, reviews, competitor pages |
| What should they do next? | Website calls to action, campaign goal |

## Useful

Ask when the answer changes the brief.

| Question | Look first in |
|---|---|
| What is different here that the alternatives cannot say? | Product pages, pricing, documentation |
| Which proof can be shown publicly? | Case studies, press, certifications |
| What must not be claimed? | Legal notes, plan limits, product documentation |
| Who decides, and who uses it, if not the same person? | Sales process, org charts |
| Where will the message run, and in which tone? | Brand guidelines, existing campaigns |

## Only when relevant

- Which segment comes first, if there are several?
- Is there a campaign spine or tagline this must fit?
- Which languages and markets?
- Which narrative framework, if the user has a preference?

## How to ask

- One question at a time in a conversation.
- Propose an answer: "I read the trigger as a failed audit. Is that right, or is it something else?"
- Stop asking once the brief can be written. Mark the rest as assumptions.
