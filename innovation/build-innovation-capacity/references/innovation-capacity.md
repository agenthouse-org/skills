# Creating Innovation Capacity

## Capacity is more than free time

Innovation capacity combines:

- protected attention;
- permission to question assumptions;
- ability to run experiments;
- a route into implementation;
- clear decision authority;
- enough operational stability to absorb learning and change.

## Intervention ladder

Apply the lowest sufficient level.

### 1. Remove avoidable RUN

- stop work whose purpose is no longer valid;
- remove redundant approvals and duplicate reporting;
- simplify before automating;
- standardize repeatable work where variation adds no value;
- automate bounded, understood processes;
- outsource suitable execution while retaining decisions and knowledge.

### 2. Protect capacity

- reserve explicit capacity rather than relying on spare time;
- prevent urgent RUN from consuming all protected capacity;
- use a small, visible portfolio of ALPHA and BUILD work;
- define who can approve experiments and bounded spending.

Ten to twenty percent is a provocative planning prompt from the book, not a universal prescription. Choose a defensible amount for the context.

### 3. Improve conversion through BUILD

- assign an owner;
- state the hypothesis and intended outcome;
- time-box discovery;
- define a minimum informative test;
- set success and stop criteria;
- decide how a validated idea enters delivery and operations.

### 4. Institutionalize constructive challenge

- schedule recurring assumption reviews;
- invite cross-functional perspectives;
- reward useful disconfirmation as well as wins;
- separate idea generation from evaluation;
- revisit the organization's definition of ALPHA periodically.

## Prioritization test

Prefer an intervention when it:

1. addresses the diagnosed bottleneck;
2. releases material attention or learning;
3. is reversible or bounded;
4. has a clear owner;
5. produces evidence within a useful time horizon;
6. does not compromise safety, compliance, or critical service.

## Capacity plan

For each action, state:

- work to stop, simplify, or protect;
- RUN, BUILD, or ALPHA classification;
- expected capacity or learning released;
- owner and authority;
- first experiment;
- measure and review date;
- operational risk and safeguard.
