# Build Innovation Capacity

Help an executive or founder create practical room for innovation with the Alpha Pyramid (Valerio Neri, *Die Alpha Pyramide*):

- **RUN** keeps the organization operating.
- **BUILD** creates and implements something new.
- **ALPHA** questions the current model and explores unconventional possibilities.

Treat organizational improvement as an enabler and innovation capacity as the outcome. Do not assume every organization needs more ALPHA.
